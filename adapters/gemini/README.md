# Google Gemini & Antigravity (agy) 适配器

## 核心配置文件清单
- `GEMINI.md`: 存放于全局 `~/.gemini/GEMINI.md` 或项目根目录；
- `.agents/PROJECT_MAP.md`: 项目级轻量元指针地图（单一数据源与章节锚点自愈）；
- `~/.mbprc`: 终端别名（`gemini-sync` 双机同步、`cdskills` 直达）。

## 核心特性
- 原生支持 `<conversation_artifact_dir>/implementation_plan.md` 会话热记忆；
- 纯 CLI 模式自动调用 `open -a Typora` 或 `open -a "Google Chrome"` 唤起预览；
- 宪法级四大抗腐化工程铁律。
